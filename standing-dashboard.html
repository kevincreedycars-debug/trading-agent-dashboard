What makes it trustworthy

Truth over polish

  • The append-only project progress log is the source of truth.
  • The now-bar names the actual current work chunk, not a vague project theme.
  • An idle state is better than stale activity. If no work is happening, the page should say so.
  • The top status line must stay truer than every other element on the page.

Setup checklist

Portable rules

  • A plain HTML status page with no build step.
  • A live-reloading preview so updates show up immediately.
  • An append-only progress log maintained alongside the page.
  • A persistent instruction to update the now-bar every meaningful work chunk.
  • A clear idle state when the project is between sessions.

Portable reference

Rule of thumb

The now-bar is the one element that has to be perfect. Everything else can lag a few minutes behind reality. The now-bar cannot, or the whole page stops being trustworthy at a glance.
