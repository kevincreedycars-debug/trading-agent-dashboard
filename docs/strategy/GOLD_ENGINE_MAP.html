Why each batch takes time

  • Vintages: prices, FRED series and events are pulled once; FRED availability is only a 36-hour proxy and event consensus vintages are still unauthenticated.
  • Scale: 19 drivers × 2 cohorts × 4 horizons × 4 endpoint groups, each with a year breakdown; ~8,400 conditioning cells; an 80 MB report per run.
  • Immutability: a new directory per run, and earlier blocks must stay byte-identical — re-verified, never overwritten.
  • Edge cases: session closes, DST, delayed endpoints, simultaneous releases — each needs a declared rule plus a regression test.
  • Review: the coordinator re-runs the batch and compares hashes, so each batch is build + test + run + document + independent review.

Not established

  • Descriptive association only; no driver is formula-eligible.
  • Calendar is archive-inferred; verified continuity is blocked.
  • Prior-return drivers share the archive that prices the outcome — not independent series.
  • Counts overlap (one anchor feeds many cells); no accuracy, profitability or trading claim.
